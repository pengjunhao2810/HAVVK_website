# HAVVK 集团档案中心 · 员工门户

参考《三角洲行动》中哈夫克集团背景设定制作的集团官方网站离线版，包含**主站、集团档案中心、员工门户**三个站点，纯前端实现，可完全离线运行。

## 站点入口

| 页面 | 说明 |
|---|---|
| `index.html` | 集团官网主站首页 |
| `admin.html` | 集团档案中心（档案分类 / 集团概况 / 档案分析 / 行动档案 / 研发档案 / 人事档案 / 公示公告），支持中英双语切换 |
| `hr.html` | 员工门户（考勤打卡 / 请假审批 / 任务与绩效 / 内部消息 / 文件柜 / 通讯录 / 会议 / 投票等） |

## 本地运行

项目为纯静态站点，任意静态服务器均可运行：

```bash
cd havvk_website
python -m http.server 8899
```

浏览器访问：

- 主站：http://127.0.0.1:8899/index.html
- 集团档案：http://127.0.0.1:8899/admin.html
- 员工门户：http://127.0.0.1:8899/hr.html

## 功能一览

**集团档案中心**

- 门户式首页：顶部大图、档案分类、集团要闻、招聘公示、研发动态、安全公告、档案检索、最近更新、档案统计、核心科技
- 7 大档案分区，支持关键词检索与文档浏览
- 图片档案点击放大、文档详情查看
- 中英双语切换

**员工门户**

- 登录 / 登出，账号权限分级（员工 / 部门主管 / 管理员）
- 考勤打卡与考勤记录查询
- 请假申请与审批（主管 / 管理员审批）
- 任务下发、任务提交（支持附件）、绩效评定
- 内部即时消息（通讯录搜索、点击头像发起对话、发送图片与文件柜文件）
- 个人文件柜（可管理、可从文件柜发送文件）
- 部门通讯录、会议管理、投票
- 快捷操作 / 自定义工作台
- 个人信息修改与自定义头像

## 技术说明

- 纯前端 HTML + CSS + JavaScript（jQuery），无后端、无构建步骤
- 业务数据保存在浏览器 localStorage / IndexedDB，离线可用
- 无需网络请求外部资源，可断网运行
